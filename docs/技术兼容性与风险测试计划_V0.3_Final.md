**Python 与依赖测试**

建议候选顺序 `[建议]`：Python 3.12、3.13、3.14。选择依据：

- Windows x64 轮包完整。
- 依赖可共同安装和导入。
- `pip check` 无错误。
- Streamlit 可启动。
- 固定数据冒烟测试通过。
- 启动、内存和运行稳定性可接受。
- 锁文件可复现。
- 版本仍可获得安全更新。

最终只选择一个主版本。当前已安装版本不能自动视为最终版本。

**本地模型基准建议**

以下仅为建议值 `[建议]`：

- 首 Token 建议小于 10 秒。
- 生成速度建议至少 5 Token/秒。
- 峰值内存建议不超过总内存 80%。
- 运行后建议保留至少 10GB 磁盘。
- 断网后仍能完成推理。
- 进程不得建立外部网络连接。
- 20 条合成提示的结构化输出成功率建议至少 95%。

未达到建议值时可使用更小模型、在线模型、AI 暂停或经产品负责人批准的能力降级。性能建议不自动否决基础统计 MVP。

**SPSS 对照条件**

- 使用相同数据行、变量类型、缺失声明、反向转换和分析样本。
- Pearson/Spearman 明确双侧、并列秩和 p 值算法。
- α 使用相同题项、固定完整样本和分值。
- 四分位数记录 SPSS 算法和设置。
- 保存 SPSS 版本、输出精度和分析样本清单。

**建议误差标准 `[建议]`**

| 指标 | 通过标准 |
|---|---|
| 有效样本数和缺失数 | 必须完全一致 |
| 均值、样本标准差 | 绝对或相对误差不超过 `1e-6` |
| 中位数、Q1/Q3 | 算法统一后误差不超过 `1e-6` |
| Pearson/Spearman 系数 | 绝对或相对误差不超过 `1e-6` |
| CITC | 绝对误差不超过 `1e-6` |
| 原始 α、标准化 α | 绝对或相对误差不超过 `1e-6` |
| p 值 | 绝对误差不超过 `1e-4`，并比较显著性判断 |
| CSV 安全转义 | 预期单元格逐字符一致 |

**差异分类**

- 算法差异：四分位数、Spearman p 值近似、并列秩和方差定义。
- 缺失处理差异：成对删除、列表删除和缺失代码声明。
- 变量处理差异：反向计分、类型转换和分组。
- 真正计算错误：相同样本、算法和参数下仍超出容差。
- 未分类差异不得通过验收。

**定向测试**

静态散点诊断：

- 验证 Pearson 线性、Spearman 单调非线性、异常值、范围限制、缺失和常量变量。
- 使用成对完整样本，显示字段和 n。
- 异常点不自动删除。
- 渲染失败不得标记为成功。

复杂抽样识别：

- 测试设计字段名与用户声明冲突。
- 测试无设计字段但用户声明复杂抽样。
- 测试“不确定”选择。
- 通过标准：依据用户声明阻断正式推断，字段名只触发确认。

授权和 HTTP 一致性：

- 分别修改 Provider、模型、URL、系统提示、用户提示、实际数据、附件和模型配置。
- 验证每个变化均改变授权指纹。
- Provider 变更后旧授权失效。
- 验证 HTTP 请求体与授权预览逐字段一致。
- 不一致时阻止发送。
- 超时后不得自动重发。

组合披露：

- 连续查询小样本均值、交叉表和差值。
- 检查累计风险提示和 D1-R 额外确认。
- 通过标准：D2/D3 零在线发送；D1-R 未获例外时零发送。

CSV 公式注入：

- 测试以 `=`、`+`、`-`、`@` 开头的文本。
- 测试一个或多个前导空格后接危险字符。
- 测试前导 Tab、CR、LF 和其他控制字符后接危险字符。
- 测试字段名中的危险内容。
- 测试合法负数、引号、逗号、换行和 Unicode。
- 通过标准：默认安全导出执行公式防护，合法数值不被破坏，CSV 结构可验证。

**风险测试表**

| 风险 | 通过标准 | 失败处理 |
|---|---|---|
| 依赖不兼容 | 安装、导入、启动和测试通过 | 锁定兼容版本 |
| 统计计算错误 | 达到分指标误差标准 | 阻断统计发布 |
| Spearman p 方法不确定 | 算法与参考工具对照通过 | 标记待验证，不发布确定性结论 |
| 四分位算法差异 | 统一算法并达到容差 | 暂不作为最终口径 |
| 复杂抽样误识别 | 依据用户声明阻断推断 | 修正声明流程 |
| 在线载荷不一致 | 预览、指纹和 HTTP 内容一致 | 禁止发送 |
| D1-R 例外未审批 | 未审批时零发送 | 阻止请求 |
| D2/D3 在线发送 | 必须为零 | 立即禁用在线 Provider |
| 组合披露 | 累计提示和例外控制有效 | 阻止高风险查询 |
| CSV 公式注入 | 前导空白和控制字符场景均安全 | 阻断导出 |
| 本地模型伪离线 | 断网、连接和 DNS 测试通过 | 禁用本地模型 |
| 哈希误作传输安全 | 同时验证 TLS、证书和 Host | 禁止上线 |
| 静态散点失败 | 明确警告并可恢复 | 不标记诊断完成 |
| SQLite 损坏 | 备份恢复通过 | 阻断发布 |
| Streamlit 状态丢失 | 已保存结果可恢复 | 修正存储边界 |
