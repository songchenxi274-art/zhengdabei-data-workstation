# 文档三：数据安全与 AI 授权规范 V0.3 Final

**统一在线 AI 边界**

| 等级 | 内容 | V1 在线发送规则 |
|---|---|---|
| D0 | 公开代码、文档、合成数据 | 允许 |
| D1 | 不具明显披露风险的一般聚合 | 经逐次授权可发送 |
| D1-R | 小组合计、稀有交叉表或可能通过差值披露的聚合 | 默认禁止；例外必须单独审批并执行逐次授权 |
| D2 | 已去直接标识符的行级数据 | 默认仅本地处理；V1 在线 Provider 不接收 |
| D3 | 原始问卷、访谈、直接标识符和受限原始数据 | V1 禁止在线发送 |

小于 5 人只是建议风险策略 `[建议]`，不是法律或统计学定律。D1-R 是聚合数据子类，不是行级 D2。

**授权指纹**

授权指纹必须绑定：

- Provider 标识。
- 模型标识。
- 规范化请求地址。
- 系统提示。
- 用户提示。
- 实际发送数据。
- 附件及其内容哈希。
- 温度、最大 Token、结构化输出模式等相关模型配置。
- 请求协议和应用版本。

- 使用稳定 canonical serialization。
- 界面预览与实际请求使用同一规范化载荷。
- Provider、模型、URL、提示、数据、附件或配置任一变化均需重新授权。
- 指纹只证明发送内容与授权内容一致，不提供传输保密性，也不能替代 HTTPS、证书验证、Host 白名单和服务器安全。

**在线请求流程**

1. 构造不可变载荷。
2. 计算完整授权指纹。
3. 显示 Provider、模型、地址、等级、字段、行数、附件和完整预览。
4. 用户逐次授权。
5. 发送前重新校验指纹。
6. 在网络层生成 HTTP 请求体并验证其规范化内容一致。
7. 不一致时取消请求。
8. 超时或断线后不得自动重发。
9. 用户重新查看和授权后才能重试。
10. 审计只保存指纹、等级、Provider、时间和结果。

**组合披露**

- 同一项目连续发送小样本聚合、交叉表或前后差值时，系统必须累计提示风险。
- 授权界面显示本会话相关查询数量和敏感等级。
- D1-R 或明显差分查询要求额外确认；D1-R 例外仍需单独批准。
- 多次结果不得自动组合成个体级数据并再次发送。
- 查询预算和隐私预算为 `[待验证]`，不属于当前新增业务模块。

**敏感数据**

- 姓名、电话、邮箱、地址、身份证号和联系方式不得进入在线 AI、普通日志或示例数据。
- 访谈原文和录音为 D3，V1 不支持自动分析或在线发送。
- 原始问卷为 D3，只允许生成脱敏分析数据。
- D2 默认只由本地程序和本地模型处理。
- 自由文本、时间地点和稀有组合必须人工确认敏感等级。

**模型权限**

- 本地模型不得自动访问外网；必须通过断网、进程连接和 DNS 测试验证离线。
- localhost 不能单独证明本地模型离线。
- 在线 Provider 只接收允许在线发送的数据等级，地址来自白名单。
- 模型不能访问本地文件、数据库、命令解释器或任意网络资源。
- 模型输出不得直接触发文件操作、系统命令或未经授权的数据修改。
- 文件写入、删除、覆盖和数据库变更必须由应用固定接口执行并需用户明确操作。

**SQLite、备份和清除**

- V1 SQLite 不提供应用层加密。
- 依赖 Windows 用户权限、目录 ACL 和可用的磁盘加密，不默认认定 BitLocker 已启用。
- 数据库、备份和导出位于仓库外。
- 备份使用 SQLite 一致性备份机制，并记录版本和文件引用。
- 删除项目需要二次确认；普通删除不承诺 SSD 安全擦除。
- 关闭项目后清理临时缓存。

**日志、缓存和异常**

- 日志不得包含原始答案、提示正文、模型响应、密钥、敏感文件名或完整用户路径。
- 缓存不得长期保存在线提示正文。
- 异常堆栈必须过滤数据值、提示内容和敏感路径。
- HTML 导出可能嵌入数据，按 D2/D3 处理。
- CSV 导出按目标内容等级管理，并执行公式注入防护。

**CSV 公式注入防护**

- 文本单元格若以 `=`、`+`、`-`、`@`、Tab、CR 或 LF 开头，可能被电子表格软件解释为公式。
- 检测不能只看字段第一个字符，还必须检查前导空格、Tab、CR、LF 和其他控制字符后的危险前缀。
- 默认安全导出对高风险文本执行中和处理，例如前置单引号 `'`。
- 普通数值负数应保持数值形式，不能被不必要地改写。
- 字段名同样执行公式注入检查。
- RFC 4180 引号转义不能单独阻止公式执行。
- 无法安全表示的异常控制字符应拒绝导出或按既定文本安全策略处理，不得静默绕过。
- 若未来提供原始未转义导出，必须单独审批并明确高风险，不属于当前 P0。
