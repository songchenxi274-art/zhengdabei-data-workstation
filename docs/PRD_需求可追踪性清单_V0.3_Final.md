# 文档一：PRD 需求可追踪性清单 V0.3 Final

**产品边界 `[已确认]`**

Research Desk 是个人优先的本地 AI 辅助数据分析工作台。第一版采用本地网页形式，统计由程序确定性计算，AI 提供方法建议和结果解释。AI 接入采用本地与在线双 Provider 架构，但基础统计不依赖任何 Provider。

第一版必须交付：

- 本地应用启动和项目工作区。
- CSV/XLSX 导入、字段类型和质量检查。
- 抽样设计用户声明。
- 描述统计、Pearson/Spearman 相关和问卷信度分析。
- 相关分析的基础静态散点诊断。
- 双 Provider 架构。
- 本地与在线模型可用状态和降级处理。
- SQLite 项目存储。
- CSV 安全导出。
- 数据分级、在线授权和日志安全。
- 测试与初学者文档。

**P0 需求**

| ID | 功能 | 验收标准 | 降级条件与行为 |
|---|---|---|---|
| RD-P0-01 | Windows 本地网页启动 | 可启动 Streamlit；无需云端账号进入首页；错误信息可理解 | AI、代理或在线服务不可用不得阻止启动 |
| RD-P0-02 | 本地项目工作区 | 创建、打开和关闭项目；用户数据位于仓库外 | SQLite 不可用时允许临时内存会话，明确提示关闭后不保留项目；基础统计仍可用 |
| RD-P0-03 | CSV/XLSX 导入 | 支持文件、编码和工作表选择；显示预览、行数和字段类型 | 单文件解析失败时拒绝该文件，不产生部分分析结果 |
| RD-P0-04 | 抽样设计声明 | 用户明确选择普通未加权独立观测、复杂抽样或不确定 | 复杂抽样或不确定时，保留描述统计但禁止正式推断 |
| RD-P0-05 | 字段类型与质量 | 识别数值、有序、分类、文本和日期；允许人工修正 | 类型未确认时禁止进入相关或信度分析 |
| RD-P0-06 | 描述统计 | 按统计规范输出有效样本数、缺失数、均值、标准差、中位数和频数 | 四分位算法未完成对照时，明确标记待验证或不输出该指标 |
| RD-P0-07 | Pearson/Spearman 相关 | 输出系数、两两 n、警告和基础静态散点诊断 | 散点渲染失败时显示成对样本摘要和警告，不伪造诊断成功 |
| RD-P0-08 | 问卷信度 | 支持原始 α、标准化 α、CITC 和删除题项后的 α | 零方差或样本不足时禁止输出无定义指标，并标记估计不稳定 |
| RD-P0-09 | 双 Provider 架构 | 本地和在线使用统一接口、统一请求模型和统一权限边界 | 架构缺失属于 P0 验收失败，不得以隐藏 Provider 代替 |
| RD-P0-10 | 模型可用状态 | 本地和在线分别显示未配置、不可用、已验证和降级状态 | 任一不可用只影响该 Provider，不阻止基础统计 |
| RD-P0-11 | AI 分析引导 | 仅解释程序和提供方法建议；不得编造统计值 | 输出无效、超时或越权时拒绝响应，不自动重试或执行操作 |
| RD-P0-12 | SQLite 项目存储 | 保存元数据、字段映射、参数和结果引用 | 数据库故障时进入临时会话，不得伪装为已永久保存 |
| RD-P0-13 | CSV 安全导出 | 用户选择字段和路径；执行公式注入防护；不自动覆盖 | 导出失败时保留结果并显示错误，不自动更换路径 |
| RD-P0-14 | 在线 AI 数据边界 | D1 经逐次授权可发送；D1-R 默认禁止且例外须单独审批；D2 默认仅本地处理；D3 在 V1 禁止在线发送 | 边界校验失败时立即禁用在线 Provider，基础统计继续运行 |
| RD-P0-15 | 降级与状态提示 | 所有暂停、受限和临时状态有显著说明、原因和恢复方法 | 不得把 AI 不可用误报为统计失败 |
| RD-P0-16 | 测试与初学者文档 | 覆盖启动、代理、数据位置、授权、降级和 CSV 安全 | 文档缺失属于 P0 验收失败 |

**P1 扩展**

| ID | 功能 | 验收标准 |
|---|---|---|
| RD-P1-01 | 完整交互式图表 | 直方图、箱线图、交互散点图、柱状图和折线图通过性能、导出与安全验收 |
| RD-P1-02 | Bootstrap 置信区间 | 固定种子可复现，并与规定算法一致 |
| RD-P1-03 | 多重比较校正 | 明确校正范围、方法和显示方式 |
| RD-P1-04 | 复杂抽样与权重 | 独立抽样规范和外部对照通过 |
| RD-P1-05 | 序数 α、McDonald's ω | 定义、适用条件和软件对照通过 |
| RD-P1-06 | PDF/Word/HTML 报告 | 嵌入数据、字段权限和公式注入风险通过验收 |
| RD-P1-07 | 多文件合并和其他格式 | 键匹配、字段冲突和丢失记录可追踪 |
| RD-P1-08 | 桌面应用封装 | 安装、更新、数据路径和权限通过验收 |
| RD-P1-09 | 更多 AI Provider | 继续遵守统一接口和逐次授权 |

V1 明确不支持：

- 云同步、多人协作和账号权限系统。
- AI 自主执行文件、系统命令、代码或数据库操作。
- 复杂抽样正式推断、加权 α 和设计效应。
- 访谈录音或原文自动分析。
- 自动缺失插补、异常值删除、题项删除或反向题猜测。
- 自动训练和自动下载模型。
